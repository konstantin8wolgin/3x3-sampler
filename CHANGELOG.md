# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-26

Initial public release for the periodic `3x3`, `n_t=1` Hubbard
auxiliary-field target. This release supports only exact one-slice methods:
`exact-enumeration`, `exact-contour`, and `exact-contour-rb`. It provides the
fixed 19,683 ordered-channel authority, immutable validated artifacts,
componentwise observable estimates and uncertainty, offline estimate/report
reproduction, the `tg-3x3` CLI, and CPU examples.
