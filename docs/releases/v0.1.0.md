# Taylor–Gauss 3x3 Sampler v0.1.0

Version 0.1.0 is the initial public release for the periodic `3x3`, `n_t=1`
Hubbard auxiliary-field target.

This release supports only exact one-slice methods: deterministic
`exact-enumeration` and the exact-law stochastic methods `exact-contour` and
`exact-contour-rb`. Their discrete authority is exactly 19,683
lexicographically ordered channels. Stochastic runs may use only
`iid_exact_categorical` or `defensive_half_uniform_importance` channel design.

The release includes immutable content-addressed run artifacts, independent
validation, offline estimate and report reproduction, componentwise
observable values and standard errors, the five-command `tg-3x3` interface,
and two CPU examples. It does not change the fixed scope described in
[`../limitations.md`](../limitations.md).
